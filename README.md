## Возможности

- 👀 каждые 20 минут — «отдых для глаз»: обычная карточка, исчезает сама через 10 с;
- 🧘 каждые 45 минут — «разминка»: важная карточка (critical) + мягкий звук,
  не исчезает, пока не закрыта;
- **умная задержка**: если вы прямо сейчас печатаете или водите мышью, карточка
  подождёт паузы в наборе — но не дольше 3 минут, потом появится всё равно;
- **детект «ушёл от стола»**: бездействие ≥ 5 минут сбрасывает таймеры —
  по возвращении напоминания не «выстреливают» пачкой;
- **пауза одной кнопкой**, в том числе на N минут (например, на время созвона);
- учёт блокировки экрана: пока экран заблокирован, таймеры сброшены;
- оба напоминания, сработавшие почти одновременно, показываются одной карточкой;
- конфиг без правки кода, применяется на лету;
- автозапуск через XFCE autostart **или** systemd --user (автоперезапуск при сбое,
  логи в journalctl).

## Быстрый старт

```bash
git clone https://github.com/SyntaxMusician/breaks_reminder.git
cd breaks_reminder
./install.sh              # или: ./install.sh --systemd
```

Установщик проверит зависимости, скопирует скрипты в `~/.local/bin`, создаст конфиг,
ярлыки меню и рабочего стола, настроит автозапуск и сразу запустит программу.

## Состав

| Файл | Назначение |
|---|---|
| `breaks_reminder.py` | основная программа: таймеры, уведомления, конфиг |
| `lock_state_watcher.sh` | следит за блокировкой экрана, пишет флаг `~/.screen_locked` |
| `toggle_pause.sh` | пауза: `toggle_pause.sh [on\|off\|минуты]` |
| `breaks_genmon.sh` | индикатор состояния для панели XFCE (xfce4-genmon-plugin) |
| `breaks_reminder.conf.example` | пример конфига |
| `install.sh` | установка / обновление / удаление |
| `*.desktop` | ярлыки меню, рабочего стола и автозапуска |
| `systemd/*.service` | юниты systemd --user (опциональный бэкенд автозапуска) |

## Как это работает

1. `lock_state_watcher.sh` определяет состояние экрана (D-Bus сигналы ActiveChanged
   + периодическая сверка через `loginctl LockedHint`, команды screenlockers, DPMS)
   и пишет флаг `~/.screen_locked` (внутри — PID watcher'а, чтобы программа могла
   распознать «мёртвый» флаг).
2. `breaks_reminder.py` раз в секунду считает активное время (пока нет флага
   блокировки и паузы) и в нужный момент показывает карточку через `notify-send`
   (fallback — zenity в отдельном процессе, чтобы не блокировать цикл).
3. Пауза — флаг `~/.breaks_paused`, им управляет `toggle_pause.sh`.

## Установка

### Новая машина

```bash
git clone https://github.com/SyntaxMusician/breaks_reminder.git
cd breaks_reminder
./install.sh              # автозапуск: systemd --user, если доступен, иначе .desktop
./install.sh --systemd    # принудительно через systemd --user
./install.sh --autostart  # принудительно через классический .desktop
```

Пакеты зависимостей для Debian/Ubuntu:

```bash
sudo apt install python3 libnotify-bin xfce4-notifyd xprintidle pulseaudio-utils dbus zenity
```

`python3` обязателен; остальное желательно (`notify-send` — уведомления,
`xprintidle` — умная задержка и детект AFK, `paplay` — звук, `dbus-monitor` —
блокировка экрана, `zenity` — fallback): чего-то нет — установщик предупредит.

### Обновление на машине, где стояла старая версия (старый install.sh)

Просто распакуйте архив (или склонируйте репозиторий) и выполните:

```bash
./install.sh
```

Установщик сам делает всё необходимое, руками ничего чистить не нужно:

1. **останавливает старые процессы** (`~/.local/bin/breaks_reminder.py`,
   `~/.local/bin/lock_state_watcher.sh`) — пути совпадают со старыми;
2. **перезаписывает скрипты** в `~/.local/bin/` (имена файлов не менялись);
3. **обновляет ярлыки** меню и рабочего стола и запись автозапуска
   (имена .desktop-файлов тоже совпадают — старые перезаписываются);
4. **создаёт конфиг** `~/.config/breaks_reminder.conf`, если его ещё не было;
5. запускает новую версию и печатает, где смотреть логи.

Примечания:

- старая строка `export PATH="$HOME/.local/bin:$PATH"` в `~/.profile` останется —
  она безвредна и не дублируется;
- старый флаг `~/.screen_locked` (текстовый формат без PID) новая версия понимает:
  он считается устаревшим через 10 минут и удаляется автоматически;
- если раньше напоминания «не приходили», вероятная причина — баг старого
  watcher'а (вывод light-locker «unlocked» распознавался как «locked», и флаг
  блокировки висел постоянно); в новой версии это исправлено.

## Настройка

Файл `~/.config/breaks_reminder.conf` (пример — `breaks_reminder.conf.example`).
Сохранённые изменения применяются на лету, перезапуск не нужен.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `eye_interval` | 20 | минуты между напоминаниями про глаза |
| `break_interval` | 45 | минуты между напоминаниями «встать и размяться» |
| `combine_window` | 90 | сек: сработали оба — показать одной карточкой |
| `break_urgency` | critical | `critical` — карточка не исчезает сама; `normal` — исчезает |
| `break_expire_ms` | 0 | таймаут карточки, мс; 0 — поведение демона |
| `break_icon` | appointment-soon | иконка карточки «разминка» |
| `eye_urgency` | normal | срочность карточки «глаза» |
| `eye_expire_ms` | 10000 | таймаут карточки «глаза», мс |
| `eye_icon` | dialog-information | иконка карточки «глаза» |
| `sound` | true | звук при «разминке» |
| `sound_file` | …/bell.oga | файл звука (проигрывается через `paplay`) |
| `quiet_ms` | 2000 | бездействие меньше этого — считаем, что печатаете, и откладываем карточку |
| `max_defer` | 180 | максимум секунд ожидания паузы в вводе |
| `afk_reset` | 5 | минут бездействия = «перерыв уже был», таймеры сбрасываются |
| `fullscreen_defer` | false | откладывать карточки, пока активное окно в fullscreen |
| `notify_on_start` | false | карточка при запуске программы |
| `log_status` | true | печатать статус раз в минуту |

## Пауза

```bash
toggle_pause.sh          # переключить
toggle_pause.sh on       # включить паузу
toggle_pause.sh off      # выключить
toggle_pause.sh 60       # пауза на 60 минут, потом возобновится сама
```

Есть ярлык «Пауза напоминаний» в меню приложений и на рабочем столе
(можно добавить на панель XFCE: ПКМ по панели → Панель → Добавить новый элемент →
Launcher → выбрать «Пауза напоминаний»).

## Индикатор на панели

Установите `xfce4-genmon-plugin`, добавьте элемент «Монитор» (Generic Monitor)
и укажите в нём команду `~/.local/bin/breaks_genmon.sh`, интервал 5–10 с.
На панели будет иконка состояния, клик переключает паузу.

## Логи и отладка

- systemd-бэкенд: `journalctl --user -u breaks-reminder -f`
  и `journalctl --user -u breaks-reminder-watcher -f`;
- autostart-бэкенд: `~/.local/state/breaks_reminder/reminder.log` и `watcher.log`
  (логи ротируются при перезапуске установщиком).

Быстрая проверка уведомлений вручную: `notify-send "Тест" "Проверка карточки"`.

## Удаление

```bash
./install.sh --uninstall
```

Убирает скрипты, ярлыки, автозапуск (обоих типов) и флаги. Конфиг и логи
остаются (пути напечатает установщик).

## Ограничения

- рассчитано на **X11**: `xprintidle`, `xprop`, `xset` под Wayland не работают —
  там умная задержка, fullscreen-детект и DPMS тихо отключаются,
  а напоминания продолжают приходить;
- вид карточек зависит от демона уведомлений (в XFCE — xfce4-notifyd;
  для «не исчезающей» карточки критичной важности нужен демон, уважающий
  urgency=critical).
